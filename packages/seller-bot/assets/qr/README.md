# QR-стикеры магазина

Сюда кладутся PDF-стикеры с QR-кодом покупательского бота
`@MahallaGoBot`. Бот отдаёт их продавцам через
**Настройки → 📥 QR-стикер для магазина**.

## Имена файлов (обязательны)

| Размер | Файл |
|---|---|
| 100 × 100 мм | `sticker-100.pdf` |
| 150 × 150 мм | `sticker-150.pdf` |
| 200 × 200 мм | `sticker-200.pdf` |
| 300 × 300 мм | `sticker-300.pdf` |

Если какого-то файла нет — соответствующая кнопка покажет
сообщение «временно недоступен», ничего не упадёт.

## Деплой

Файлы коммитятся в репо и попадают на прод через `git pull`
(скрипт `deploy/run/04-update.sh`). После добавления файлов
просто перезапустите seller-bot:

```bash
ssh mgo-app 'sudo systemctl restart mahallago-seller-bot'
```
